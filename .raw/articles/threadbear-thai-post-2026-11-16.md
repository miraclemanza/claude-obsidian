สั่ง Claude Code หรือ Codex ทำงานไว้ แล้วปิดแอปได้เลย โดยไม่ต้องค้างหน้าต่างไว้รอให้งานเสร็จ

Threadbear เป็นแอป Open Source บน macOS ที่ใช้บัญชีและ CLI login ของ Claude Code กับ Codex ที่มีอยู่แล้ว ตัวแอปแยกหน้าจอออกจากตัวรันเบื้องหลัง ส่วนงานที่รอให้เราตอบหรืออนุมัติจะรวมไว้ใน Inbox

ฟีเจอร์เด่น

• Decision Buttons ตอบคำถามของ Agent ด้วยการกดเลือก ไม่ต้องพิมพ์ตอบทุกครั้ง
• Inbox แยกงานที่กำลังรันออกจากงานที่รอเรา และเก็บงานที่เสร็จแล้วเข้า Archive ได้ในคลิกเดียว
• Background Runner ให้ Agent ทำงานต่อได้แม้ออกจากแอปหรืออัปเดตแอป
• แอปคู่บน iPhone ใช้ติดตามงานและอนุมัติคำสั่งผ่าน Convex ที่ตั้งเอง
• TypeScript Patches เพิ่มปุ่มหรือแผงใหม่ในแอปได้ รวมถึงให้ Agent ช่วยเขียน patch
